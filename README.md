# ✍️ Spelling Correction using Jaccard Similarity

## 📌 Description
This project implements a spelling correction system using Jaccard Similarity. It compares the similarity between the input word and a dictionary of correct words to suggest the most appropriate correction.

## 🧠 Concept Used
Jaccard Similarity measures similarity between two sets.

Formula:
J(A, B) = (Intersection of A and B) / (Union of A and B)

In this project:
- Words are converted into character sets or n-grams
- Similarity score is calculated
- Word with highest similarity is returned as correction

## 🚀 Features
- Detects incorrect words
- Suggests most similar correct word
- Simple and efficient implementation
- Works on basic NLP principles
